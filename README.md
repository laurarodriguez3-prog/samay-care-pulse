# Samay Care Hub

SAMAY CARE — Plataforma Inteligente para la Prevención de la Sobrecarga Hospitalaria

Quiero crear una página web moderna, profesional e interactiva llamada SAMAY CARE.

Samay Care es una plataforma inteligente para la detección y prevención de la sobrecarga organizacional en entornos hospitalarios. La plataforma analiza información de los servicios hospitalarios para identificar señales de riesgo y ayudar a los responsables a tomar decisiones preventivas.

La web debe tener una estética HealthTech moderna, limpia, humana y tecnológica, utilizando principalmente los colores:

Verde

Celeste

Blanco

El diseño debe transmitir bienestar, confianza, prevención, tranquilidad y tecnología.

3. SECCIÓN “¿CÓMO FUNCIONA?”

Debajo del Hero crear una sección:

¿Cómo funciona Samay Care?

Texto:

“Samay Care transforma datos hospitalarios y señales de bienestar en información preventiva para ayudar a identificar servicios que podrían estar experimentando una sobrecarga.”

Mostrar un proceso de 4 pasos:

01 — Recolectar

Samay Care utiliza información disponible del entorno hospitalario, como demanda de atención, turnos, carga de trabajo, ausencias e incidencias.

02 — Analizar

La plataforma analiza tendencias y genera indicadores de riesgo para cada servicio.

03 — Detectar

Identifica qué áreas presentan mayor presión y en qué momentos se concentra el riesgo.

04 — Prevenir

Genera información y recomendaciones que ayudan a los responsables a tomar acciones preventivas.

Representar los cuatro pasos como un flujo visual:

Datos → Análisis → Detección → Prevención
